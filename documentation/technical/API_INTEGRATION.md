# API & Integration Documentation

Dream Supreme provides a secure set of Webhook endpoints and REST APIs to allow seamless integration with 3rd party services, such as property portals (Property24, PrivateProperty) or marketing platforms (Facebook Lead Ads).

> **Note**: Our public API is currently in Beta. Endpoints and schemas are subject to change.

## Authentication

All API requests must be authenticated using a long-lived Service Token generated by your Agency Admin.

Include the token in the `Authorization` header of your HTTP requests:
```http
Authorization: Bearer ds_prod_abc123...
```

## 1. Webhooks: Inbound Leads

You can configure your external marketing platforms to POST lead data directly into your Dream Supreme CRM pipeline. 

**Endpoint**: `POST https://api.dreamsupreme.co.za/v1/webhooks/lead`

### Request Body Schema (JSON)
```json
{
  "source": "property24",
  "campaign_name": "Summer 2026 Promo",
  "lead_name": "Jane Doe",
  "lead_email": "jane@example.com",
  "lead_phone": "+27821234567",
  "property_reference": "PROP-1029",
  "message": "I would like to arrange a viewing for this weekend."
}
```

### Lead Auto-Assignment
When a lead is ingested via this webhook, it bypasses the manual entry queue and is passed directly to the `assign_lead_round_robin()` database RPC. The system will instantly assign the lead to the next available agent and dispatch a push notification to their device.

## 2. API: Exporting Deals (Read-Only)

You can programmatically retrieve your agency's deals for external reporting or accounting integrations (e.g., Xero).

**Endpoint**: `GET https://api.dreamsupreme.co.za/v1/deals`

**Query Parameters**:
- `status` (optional): Filter by stage (e.g., `Registered`, `OTP Signed`)
- `date_from` (optional): ISO 8601 Date
- `date_to` (optional): ISO 8601 Date

### Response Example
```json
{
  "data": [
    {
      "deal_id": "d-998811",
      "property_address": "123 Main St",
      "stage": "Registered",
      "gross_commission": 150000.00,
      "registration_date": "2026-08-01T10:00:00Z"
    }
  ],
  "pagination": {
    "total_records": 1,
    "current_page": 1
  }
}
```
